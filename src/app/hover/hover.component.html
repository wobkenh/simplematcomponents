Hover

You can react to mouseenter and mouseleave events on the table cells using the table column methods withOnMouseEnter and withOnMouseLeave. A use case for this might be selecting or styling the table rows or table cells depending on the current mouse over.

The whole table cell is the hover target. After your callback ran, both the cell styling (withNgStyle/withNgClass) and the row styling (rowNgStyle/rowNgClass) are recalculated, so you do not need to change the data or the columns to make your styling change visible.
